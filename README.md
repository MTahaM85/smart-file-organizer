# Smart File Organizer

A simple Bash script for automatically organizing files based on their extensions.

## Overview

**Smart File Organizer** is a command-line Bash application that helps organize files in a selected directory.

The program identifies files based on their extensions and moves them into appropriate directories such as:

* `Images`
* `Documents`
* `Videos`
* `Audios`
* `Archives`

It also creates the required directories automatically if they do not already exist.

The application keeps a detailed activity log in `activity.log` and provides a final report showing how many files were moved into each category.

---

## Features

* Organize files automatically based on their extensions
* Support for multiple file formats
* Automatically create required directories
* Detect duplicate filenames before moving files
* Allow the user to choose a new name when a duplicate exists
* Display a final transfer report
* Record application activities in a log file
* Use Bash associative arrays to manage file extensions and statistics

---

## Supported File Formats

| Category  | Extensions                                                |
| --------- | --------------------------------------------------------- |
| Images    | `jpeg`, `jpg`, `png`, `gif`, `webp`, `svg`, `bmp`, `heic` |
| Documents | `pdf`, `docx`, `txt`                                      |
| Videos    | `mp4`, `mkv`, `avi`, `mov`, `hevc`                        |
| Audios    | `mp3`, `wav`, `flac`, `m4a`                               |
| Archives  | `zip`, `rar`, `7z`, `tar`                                 |

## How It Works

When the application starts, it performs the following steps:

1. Displays the application title.
2. Asks the user for the destination directory.
3. Checks whether the specified directory exists.
4. Creates the required category directories if necessary.
5. Checks the files in the current directory against the supported extensions.
6. Moves matching files into their corresponding category.
7. Checks for duplicate filenames before moving each file.
8. Asks the user for a different filename if a conflict occurs.
9. Displays a final report containing the number of transferred files.
10. Records important events in `activity.log`.

### Example

Suppose the current directory contains:

```text
photo.jpg
book.pdf
movie.mp4
song.mp3
backup.zip
```

After running the program, the destination directory will contain:

```text
Destination/
├── Images/
│   └── photo.jpg
├── Documents/
│   └── book.pdf
├── Videos/
│   └── movie.mp4
├── Audios/
│   └── song.mp3
└── Archives/
    └── backup.zip
```

## Logging

The program records its activities in:

```text
activity.log
```

Each log entry contains:

```text
Timestamp | Level | Operation | Description
```

For example:

```text
2026-09-11 22:15:32 | INFO | MOVE | /home/user/photo.jpg -> /home/user/Images/photo.jpg
```

The log records events such as:

* Application startup
* Missing destination directories
* Directory creation
* Detected file formats
* File transfers
* Duplicate filename conflicts
* Application termination

The log levels currently used are:

* `INFO` — normal application activity
* `WARNING` — an unusual situation that does not necessarily stop the application

## Usage

Make the script executable:

```bash
chmod +x script.sh
```

Run the application:

```bash
./script.sh
```

The program will ask for the name of the destination directory.

For example:

```text
Enter the destination directory name: Organized
```

---

## Final Report

After the organization process is completed, the program displays a summary similar to:

```text
File transfer results

Images: 5
Documents: 3
Videos: 2
Audios: 4
Archives: 1
```

This shows how many files were successfully processed for each category.

## Notes

The program currently organizes files located in the **current working directory** and moves them to the selected destination directory.

Only the file extensions listed in the supported formats are processed. Other files remain untouched.
